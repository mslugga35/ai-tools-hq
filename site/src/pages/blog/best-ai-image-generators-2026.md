## 3. Stable Diffusion - Best Free Option

**Price:** Free (run locally) | **Hosted:** Varies

Stable Diffusion is open-source and can run on your own computer for free. Unlimited generations, complete control.

**Pros:**
- Completely free
- Run locally = private
- Huge model ecosystem
- No content restrictions

**Cons:**
- Requires technical setup
- Needs good GPU
- Steeper learning curve

**Best for:** Technical users, privacy-conscious, unlimited needs

## Tips for Better Results

1. **Be specific** - "A golden retriever playing in autumn leaves, soft afternoon light, 35mm photography" beats "dog in leaves"

2. **Specify style** - Add "digital art", "oil painting", "photograph", etc.

3. **Use negative prompts** - Tell it what NOT to include

4. **Iterate** - Generate multiple versions and refine

5. **Learn from others** - Study prompts in community galleries
